# 食谱小本 🍳

一个**手机、电脑都能用**的本地食谱管理应用：记录菜谱、管理冰箱、生成购物清单、写探店手记，还内置 117 道经典菜谱。
单文件 HTML + 原生 JS，**无需安装、无需登录、默认不联网**，所有数据保存在你自己的设备里。

**在线使用：<https://shidangyese.github.io/recipe-book/>**（手机用 Safari/Chrome 打开后可「添加到主屏幕」，像 App 一样用）

## 功能

| 模块 | 能做什么 |
|---|---|
| 🍳 食谱 | 新建/编辑/删除；食材（名称 + 用量 + 克数）、分步骤做法、小贴士、标签、分类、用时、份量、大概热量、封面图（自动压缩）；「做过一次」一键计数；🔥 烹饪手记（日期 + 星级 + 成品照片 + 感想） |
| 📚 菜谱库 | 内置 117 道经典菜谱（家常菜/荤菜/素菜/凉菜/汤羹/主食/早餐/甜品/烘焙），看中哪道「存入我的食谱」就能自由改 |
| 🍽️ 探店手记 | 店名、招牌菜、人均、位置、日期、星级、感想，可搜索 |
| 🔍 食材找菜谱 | 输入一个食材按匹配度推荐；多个食材 = 组合搜索；🧊 按冰箱推荐，缺得最少的排最前 |
| 🧊 冰箱 | 70+ 类食材内置保鲜时长，存进来就显示到期时间，按「已过期 / 尽快吃掉 / 本周内 / 还很新鲜 / 耐放」分组；「开始做饭」自动对照冰箱列出要买的东西 |
| 🛒 购物清单 | 一键把食谱食材加进清单（自动去重、带克数）、勾选已买、复制成文字、导出 .txt / .csv |
| 📤 分享 / 导入 | 文字菜谱复制或系统分享；分享码互传，对方粘贴即可导入（支持一次多道、也支持整份备份 JSON） |
| 🖼️ 图片识别导入 | 菜谱截图/手写菜谱拍照，本地 OCR 识别中文后自动填好食材、步骤、热量（图片不上传；首次需联网下载约 5MB 引擎） |
| 💾 数据 | 导出/导入 JSON 备份（合并或覆盖）；可选数据库同步（见下） |
| 🌗 外观 | 深色 / 浅色 / 跟随系统，手账风界面 |

## 三种用法

**1）纯离线（最简单）**
双击 `index.html` 就能用。数据只存在当前浏览器里，换设备请用「导出备份 → 导入备份」。

**2）本地服务 + SQLite 同步（推荐多设备）**
需要 Node.js 22.5+（用到内置 `node:sqlite`，更低版本会自动退回 JSON 文件存储）：

```bash
node server.js
```

然后电脑打开 <http://127.0.0.1:8123>，同一 WiFi 下的手机打开 `http://电脑IP:8123`。
此时所有数据自动存进同目录的 `recipes.db`，多设备读写同一个库，断网自动退回本地模式。

**3）放到网上**
本仓库已开启 GitHub Pages，直接访问上面的在线地址即可；也可以把 `index.html` 丢到 Vercel / Netlify / Cloudflare Pages。
静态托管没有 `/api/sync` 后端，应用会自动以「仅本地模式」运行（不受影响）。

## 数据与隐私

- 数据默认只存在**当前设备、当前浏览器的 localStorage**，不上传任何服务器；没有账号、没有埋点。
- 清除浏览器数据会清掉内容，重要食谱请定期「导出备份」。
- 运行 `node server.js` 时，数据只写进你本机的 `recipes.db`（已加入 `.gitignore`，不会被提交）。
- 图片识别用本地 OCR，图片本身不出设备。

## 文件结构

```
index.html            应用本体（单文件：HTML + CSS + JS）
server.js             本地服务：静态托管 + SQLite 同步 API
recipes.db            本地数据库（运行时生成，不提交）
manifest.webmanifest  PWA 配置
sw.js                 Service Worker（离线缓存）
icon-*.png            图标
gen-icons.js          重新生成图标的脚本（node gen-icons.js）
使用说明.md            更详细的使用说明
```

## 技术说明

单文件 HTML + 原生 JavaScript，无依赖、无构建步骤。UI 为手账风：鼠尾草绿 + 米白。
改主题色直接编辑 `index.html` 顶部的 CSS 变量（`--accent` 等）。
同步协议走 `/api/sync`（POST 全量 + 墓碑），按条目「最后写入者胜」合并。
